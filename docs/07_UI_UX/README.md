# 07_UI_UX

UI/UX guidelines and design decisions for the React frontend (`apps/web`).

## What belongs here

- Design system notes (layout conventions, component usage guidelines)
  once established.
- Wireframes/mockups for modules and key screens as they're designed.
- UX decisions and their rationale (e.g. navigation structure, how
  approval/workflow status is surfaced to users).
- Accessibility guidelines.

## What doesn't belong here

- Actual component code — that lives in `apps/web/src/`.
- Business requirements driving a screen's existence — see
  `02_Requirements/`.
