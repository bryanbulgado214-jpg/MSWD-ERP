# 01_Vision

Why this project exists, at a level above any single module or technical
decision.

## What belongs here

- Project charter / vision statement — the problem being solved and for
  whom.
- Scope statement — what MSWD ERP is and, just as importantly, what it is
  explicitly not (yet).
- Stakeholder list — who the system serves and who makes which decisions.
- High-level roadmap — the intended order of modules/phases (e.g. Check
  Registry → Budgeting/Accounting/Procurement/Inventory/HR foundation →
  Invoice Writer), without implementation detail.

## What doesn't belong here

- Detailed feature requirements — those go in `02_Requirements/`.
- Technical architecture decisions — those go in `03_Architecture/` or
  `10_Decisions/`.
